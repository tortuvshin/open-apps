# InvoiceFlowAI

InvoiceFlowAI is an open-source desktop application for collecting, recognizing, organizing, and summarizing electronic invoices.

## What it does

The application can collect supported invoice attachments and download links from email, process PDF, OFD, and XML files, extract invoice fields with OCR, remove duplicates, organize files, and export an Excel summary. Low-confidence results remain visible for review.

## Why it is useful to study

The repository demonstrates a practical Python desktop workflow that connects mailbox access, document parsing, OCR, duplicate detection, manual review, file organization, and spreadsheet output. It is aimed at repetitive expense preparation rather than replacing accounting judgment.

## Platforms

Current GitHub releases provide a Windows installer, a portable Windows package, and a macOS Apple Silicon disk image.

## Limits

Recognition results should be checked before financial use. If the user enables an external OCR or model provider, the relevant invoice content is processed by that configured service.
