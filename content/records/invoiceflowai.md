## Why it is listed

InvoiceFlowAI is a Windows and macOS desktop application for collecting supported PDF, OFD, and XML invoices from email, reviewing OCR results, organizing files, and preparing an Excel reimbursement summary. Its Apache-2.0 Python source and current installers are public. The project is useful to study as an end-to-end document-processing workflow rather than a standalone OCR library.

Recognition results need human review before financial use. If an external OCR or model provider is enabled, invoice content is processed by that configured service.
