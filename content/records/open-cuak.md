## Why it's listed

Open-CUAK (Open Computer Use Agent Kit) is an Apache-2.0 project from Aident AI for running and managing reliable browser automation agents at scale. It bundles a Next.js web app, a Chrome extension, a remote browser service built on browserless, and a Supabase backend, all started with a single Docker quick-start script.

It is a useful codebase to study if you want to see how an agent drives a real browser session, streams it back to a UI, and stores runs, without depending on a hosted operator product.
