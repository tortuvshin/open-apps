## Why it's listed

Kaeso is a usable self-hosted AI gateway, not a library or a tutorial. You run it yourself: applications call one OpenAI- or Anthropic-compatible API, and Kaeso applies SSO, budgets and request logs before forwarding requests to the providers you configure.

Official site: https://kaeso.app. Docs: https://docs.kaeso.app. Source: https://github.com/logicplanes/kaeso. MIT licensed. The documented install path is Docker Compose.
