## Why it's listed

Mercury CLI is an Apache-2.0 terminal coding agent for macOS, Linux and Windows. It runs parallel sessions on one screen, delegates to crewmates in isolated git worktrees with project file leases, and works with 22 model providers or local models through Ollama, LM Studio, vLLM or llama.cpp.
