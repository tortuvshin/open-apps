Kinetic Life OS is a calm, local-first personal workbench that brings
projects, daily actions, health records, workouts, calendar review, and
inspiration back together through dates. It is an installable PWA: there is
no account, backend, or automatic cloud sync, and the app can be explored
with fictional demo data before starting from an empty workspace.

## Why it is useful to run or study

- **A complete local-first workflow.** The app covers more than a single
  tracker: users can move between project progress, daily tasks, calendar
  review, health trends, training plans, and an inspiration trail.
- **A small, inspectable PWA.** The GPL-3.0 JavaScript codebase shows how a
  browser application can persist structured personal records locally,
  provide JSON backup and restore, and remain usable without an account.
- **A quieter productivity model.** The interface emphasizes dated review,
  long-term direction, and visible evidence of change instead of turning
  every part of personal life into a score or notification feed.

The trade-off is intentional: records stay in the current browser profile by
default, so users who need cross-device access must handle their own JSON
backup and transfer.
