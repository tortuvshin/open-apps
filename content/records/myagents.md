## Why it's worth listing

MyAgents is a desktop app for keeping agent work with the project files it uses. Each workspace can use its own runtime and tools. The task center keeps schedules and run history, so repeated work does not have to start with a new chat each time.

The codebase is an example of a Tauri app that combines local file workspaces, more than one agent runtime, and a persistent task system. Version 0.5.14 has installers for Apple Silicon, Intel Macs, and Windows x64. The app is free; model access requires a compatible provider subscription or API configuration and may incur separate charges.
