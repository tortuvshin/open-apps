whyListed:
  - Start and stop dictation with a keyboard shortcut, then insert text into the original input field.
  - Choose Gemini or supported Apple on-device recognition, with configurable writing styles and terminology assistance.
  - Native Swift implementation offers an example of macOS audio capture, accessibility-based input and safeguards against duplicate or misplaced text.
bestFor:
  - Mac users who want keyboard-triggered dictation in their everyday apps.
  - Developers exploring native macOS speech input and text-insertion workflows.
caveats:
  - Requires macOS 15 or later; current downloadable builds are ad-hoc signed development builds, not Apple notarized.
  - Gemini mode sends audio to Google and requires your own API key; API charges may apply. Apple on-device recognition depends on device and language support.
  - Automatic input does not work in every app. Recent transcript history is stored locally in plain text.
